# Orientações de continuidade

- Leia `docs/13_contexto_e_plano_cnn.md` antes de alterar câmera, CNN,
  aprendizado, controle ou desvio de obstáculos. Consulte também os guias
  específicos indicados nesse documento e confira o código atual.
- Diferencie funcionalidade implementada, resultado de bancada e proposta.
  Não apresente inferência integrada ou autonomia física como já validadas.
- A cada alteração solicitada, faça um commit com mensagem descritiva após
  as verificações pertinentes. Inclua somente as alterações da tarefa.
  Se não conseguir fazer o commit, informe explicitamente a limitação.
- Mantenha o contexto atualizado quando decisões ou implementações mudarem.
  Os itens futuros comentados são um plano, não autorização para ativá-los
  todos de uma vez. Treinamento somente com o carrinho parado.
