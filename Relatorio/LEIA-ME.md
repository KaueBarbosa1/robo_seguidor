# Relatório para Overleaf
Importe o ZIP como novo projeto no Overleaf. Selecione main.tex como documento principal e pdfLaTeX como compilador. Compile duas vezes para atualizar sumário e numeração.
Preencha autores e disciplina no início de main.tex. O modelo original foi preservado na pasta Relatorio.
O texto e as figuras são autocontidos; nenhuma imagem depende de caminho externo. A pasta evidencias contém os registros utilizados, sem necessidade de executá-los.
Este pacote não foi compilado localmente porque não há compilador LaTeX instalado neste ambiente.
